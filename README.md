# ฟิลเตอร์หน้าของฉัน (Face Filter) · 0214381 Lab 3

Template ฟิลเตอร์ใบหน้าแบบเดียวกับ IG / TikTok ทำงานบนเว็บด้วย A-Frame 1.5.0 + MindAR 1.2.5 (Face Tracking) ใช้กล้องหน้า ติดสติกเกอร์ภาพ PNG ไว้บนจุดต่าง ๆ ของใบหน้า และมีปุ่มเปลี่ยนโทนสีภาพ **ไม่ต้องมีโมเดล 3D**

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | หน้าเว็บฟิลเตอร์ **แก้ไฟล์นี้** |
| `assets/glasses.png` `hat.png` `mustache.png` `blush.png` | สติกเกอร์ตัวอย่าง เปลี่ยนเป็นรูปของตัวเองได้ |

## ขั้นตอน (เหมือน Lab 1)

1. กด **Use this template → Create a new repository** ตั้งชื่อ `ar-filter` เลือก **Public**
2. **Settings → Pages** เลือก Branch **main** และ **/ (root)** แล้วกด **Save**
3. รอ 1–2 นาที เปิด `https://<ชื่อผู้ใช้>.github.io/ar-filter/` บนมือถือ อนุญาตกล้อง แล้วหันกล้องหน้าเข้าหาใบหน้า (ครั้งแรกโหลดโมเดลประมาณ 5–15 วินาที)

## ใช้สติกเกอร์ของตัวเอง

1. ทำรูป **PNG พื้นหลังโปร่งใส** (เช่น Canva → ดาวน์โหลด PNG ติ๊ก "พื้นหลังโปร่งใส" หรือวาดเองแล้วลบพื้นหลัง) ขนาดไม่เกิน 1000 px
2. ใน Repository เข้าโฟลเดอร์ `assets` → **Add file → Upload files** → Commit
3. ใน `index.html` เพิ่มบรรทัดใน `<a-assets>` เช่น `<img id="star" src="assets/star.png">` แล้วใช้ `src="#star"`
4. ตั้ง `width` และ `height` ให้สัดส่วนเท่ารูป เช่น รูป 800×400 → width 0.8 height 0.4

## แก้ปัญหาเบื้องต้น

- **หมุนโหลดนาน / ค้าง:** ใช้ Wi-Fi ที่เร็วพอ รีเฟรช 1 ครั้ง ปิดแท็บอื่น
- **สติกเกอร์ไม่ตรง:** ปรับ `position` ทีละ 0.05 (x ซ้าย–ขวา, y ขึ้น–ลง, z ยื่นออกจากหน้า)
- **รูปเป็นกรอบสีดำ/ขาว:** รูปไม่ใช่ PNG โปร่งใส หรือขาด `transparent="true"`
- **รูปไม่ขึ้น:** ตรวจชื่อไฟล์ให้ตรงทุกตัวอักษร (ตัวพิมพ์เล็ก–ใหญ่มีผล) และ id ใน `src="#..."` ต้องตรงกับ `<img id="...">`
- **หน้าขาวทั้งหน้า:** มักเกิดจากคอมเมนต์ `<!--` หรือแท็กปิดหาย
